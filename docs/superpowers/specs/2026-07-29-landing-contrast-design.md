# 랜딩페이지 대비 개선 디자인

## 목표

배포 랜딩페이지에서 확인된 히어로 목차, 연사 카드 CTA, FAQ 카드의 낮은 대비를
테마 토큰 기반으로 개선한다.

## 결정 사항

### 히어로 목차

- 어두운 배경 모드에서는 비활성 목차도 밝은 본문색을 82% 사용하고 짧은 텍스트 그림자를 더한다.
- 활성 목차는 밝은 본문색을 사용하며, 기존 마커 길이 변화로 활성 상태를 구분한다.
- 섹션 경계가 목차를 가로지를 때 각 링크의 세로 중심점 뒤에 있는 섹션 모드를 개별 적용한다.
  따라서 위 링크가 히어로, 아래 링크가 다음 섹션 위에 있어도 각각 읽을 수 있는 색을 유지한다.

### 연사 카드 CTA

- 항상 어두운 연사 카드 안에서만 쓰는 `--session-accent` 토큰을 추가한다.
- 토큰은 `--primary` 48%와 카드의 밝은 `--paper`를 혼합해 브랜드색을 유지하면서
  어두운 사진·스크림 위의 가독성을 확보한다.

### FAQ 카드

- 라이트 모드 FAQ는 회색 카드 대신 `--card`의 흰 표면을 사용한다.
- 기존의 넓은 단일 그림자 대신 가까운 접촉 그림자와 낮은 확산 그림자를 겹친다.
- 외곽선은 추가하지 않는다.

## 검증

- CSS 토큰과 선택자 회귀 테스트를 먼저 실패시킨 뒤 구현한다.
- 목차 링크별 배경 모드 동기화와 정리 동작은 가짜 IntersectionObserver로 검증한다.
- 전체 테스트와 타입 검사를 실행한다.
- 실제 랜딩페이지를 데스크톱과 모바일 폭에서 확인한다.
