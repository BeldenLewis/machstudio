## 4. 이 세션에서 배운 함정 (8/21 문서의 §4에 더한다)

| 함정 | 내용 |
|---|---|
| 스텁한 전송 | JSDOM 에서 `sendBeacon`/`fetch` 를 스텁하면 CORS·preflight 가 적용되지 않는다. **전송 경로는 실제 브라우저에서** |
| `sendBeacon` + CORS | 항상 credentials 모드다. `Access-Control-Allow-Origin: *` 로는 막힌다 — Origin 반사 + `Allow-Credentials` 필요 |
| 위치 인덱스 매핑 | 사이트가 문항을 하나만 추가해도 전부 밀린다. 조용히 틀린 칸에 저장되는 게 0건보다 나쁘다 |
| fail-closed 배포 순서 | `getPublicAppOrigin()` 처럼 fail-closed 로 바꿀 땐 **환경변수를 먼저** 넣어라 |
| 리베이스 후 재검증 | 리베이스하면 전체 테스트를 **다시** 돌려야 한다(§5) |
| 템플릿 리터럴 주석 | 생성 스크립트의 템플릿 문자열 안 주석에 백틱을 쓰면 문자열이 끊긴다. 이 세션에서 또 걸렸다 |
| Prisma Json 입력 | 고정 키 타입은 `InputJsonValue` 에 안 맞는다 — 스프레드나 JSON 왕복으로 넓힌다 |

## 5. 내가 한 실수 (기록으로 남긴다)

1. **리베이스 뒤 전체 테스트를 다시 안 돌리고 main 에 올렸다.** 내 아임웹 기준선 테스트가 빨간 채로 있었다.
   원인은 hook-lee 의 #153 이 인덱싱 규칙을 바꿨는데 내 테스트가 그 앞의 계약을 박아 둔 것 — 코드가 아니라
   내 기대값이 틀렸다. `1bd137a` 로 고쳤다.
2. **"에듀테크 수집이 됩니다" 라고 말했는데 전송이 막혀 있었다.** 로직은 맞았지만 스텁한 전송으로 검증해서
   CORS 를 놓쳤다. "실제 제출 1건 확인이 필요하다" 는 단서를 달아 둔 것이 유일한 방어였다.
3. **진단이 하루 낡아 있었다.** `.form-group` 하드코딩을 원인으로 짚었는데, 그 사이 hook-lee 가 이미
   소스별 셀렉터를 넣어 둔 상태였다. 리베이스로 뒤늦게 알았다 — **분석 전에 origin/main 을 먼저 당겨라.**
